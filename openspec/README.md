# Planning record

The proposal, design, spec, and task list that built this repo, copied here
from the `node-sdk` change in the `hush-hush-sdk` planning repo so this
SDK's design rationale doesn't depend on that repo being reachable.

- `proposal.md` — why this repo exists, what it changes
- `design.md` — the technical decisions and their rationale
- `specs/sdk-node/spec.md` — the behavior contract, in testable requirements
- `tasks.md` — the implementation checklist

These are a historical record, not living documentation — see
[CONTRIBUTING.md](../CONTRIBUTING.md) for how the repo actually works today.
